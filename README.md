# JAIDE
This app was originally created to be a time calculator to assist Master Control Operators in performing time math.

The app allows you to add or subtract time, as well as input a "Start of Message" time to help for special use cases.

The name "JAIDE" is derived from the words "JIP" which means "Join In Progress" in television terms and "Paids" which are like commercials, but are typically longer.

A situation where time math is necessary, and must be done quickly is when you have to "JIP a paid" which is why we thought this name was fitting.
